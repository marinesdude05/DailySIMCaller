# v47 Local Call History Preview

This optional debug APK is a **separate installation** of Daily SIM Caller,
with the application ID `com.example.dailysimcaller.localpreview`.
It intentionally does **not** replace or modify the installed v46 app.

## Differences from v46
- Removed Google Sheets Connect/Reconnect, Sync Now, Disconnect, and status panels.
- Removed Google Sheets OAuth flows, upload jobs, and API integration.
- Retained the app-private per-device call-history database and in-call recording.
- Placed the 20 most recent outgoing calls at the bottom of the main screen,
  visible whether or not the Admin Only switch is enabled.
- Kept calling, number-list refresh, and setup utilities.

## Important
The debug certificate generated by GitHub Actions may differ between workflow
runs. This preview uses a distinct application ID to avoid uninstalling the
existing app or deleting existing local history. Its history will initially be
empty and will populate from calls made through this preview when Android
grants it the default Phone role. Existing v46 local history stays with v46.

The source project's `main` and `feature/v46-direct-google-sheets` branches
remain unchanged. This preview does not revoke previously granted Google
permissions; it simply makes no Sheets API calls.

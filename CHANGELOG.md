# Change log

## v1.3.21 — Ordered Permissions (source candidate)
- Removed the competing numbered setup wizard and Battery Settings shortcut.
- Placed Fix Permissions directly beneath Help Me Set Up.
- Sequenced Phone permission, Notifications, default Phone, default Home, and Shut Down Helper as one checklist.
- Added a flashing three-dot instruction **inside the app** before App Info; Android's own Settings cannot be altered.
- Fixed denied Phone-app recovery to use Default apps instead of Accessibility restricted settings.
- Preserved the auto-retry and call/restart/shutdown systems. Source only; not a signed build.
